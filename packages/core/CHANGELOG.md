# @ahead-ui/core

## 0.2.0

### Minor Changes

- Add comprehensive animation system to tailwind preset
  - 30+ new animations (fade-in, scale-in-bounce, wiggle, shake, float, pulse-soft, etc.)
  - Utility classes: pressable, hover-lift, hover-scale, hover-glow, glass, skeleton
  - Stagger animations for lists (stagger-children)
  - Task-specific animations (task-complete, checkbox-animated)
  - Loading states (loading-dots, badge-pulse)
  - Box shadows with glow effects and elevation system
